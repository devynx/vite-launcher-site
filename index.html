01 / Features Reads your disk. Not your account.

The launcher that
gets out of the way.

Vite indexes what Steam, Epic, and GOG already installed, launches through each store’s own protocol, and leaves ownership checks, updates, and achievements alone. Then it disappears into the tray.

01

Quick-launch palette

Ctrl + Shift + Space opens fuzzy search over everything installed. Enter launches; Shift + Enter opens the game page.

Global hotkey
02

A tray that remembers

Recents and running games sit in the system tray with a targeted Stop, so the window can stay closed while the library stays one click away.

Recent + running
03

Your order, not the store’s

Collections, tags, notes, and smart shelves for updates, unplayed games, and store source — plus Pick for me when the backlog wins.

04

Per-game launch profiles

Arguments, working directory, environment variables, a pre-launch command, and run-as-admin — while the store’s own launch stays the default.

Args · env · admin

Keep the last seven daily SQLite snapshots, export the catalog as JSON and import it back, or run entirely from a vite.portable marker.

Local data

An update check you ask for

A manual check against an HTTPS JSON release manifest, which opens the new installer in your browser. No silent background updates.

Skip remote artwork and player history in offline mode; missing images fall back to generated covers and scan errors stay readable.

No network required

No store, no payments, no downloads of game content. Vite is a catalog and a launcher for games you already own.

02 / Overlay Shift + Tab

One hotkey.
No alt-tab.

A Steam-like overlay over whatever you are playing: the running game, a session timer, an approximate latency read, and the current boost state. Close it and you are back in the game.

  • Session timerTicks from the moment the game starts, not from when you opened the overlay.
  • Latency probeOne ICMP echo to 1.1.1.1, at most once every five seconds. Nothing is stored.
  • Boost stateSee whether Game Boost is on without leaving the game.
  • Open ViteOne button back to the library, the session, and the stop control.
Honest limitation The overlay is a separate always-on-top window, not an injected hook. It covers desktop, windowed, and borderless games; games in exclusive fullscreen may draw over it.

What Discord receives The activity text, the session start time, and the Vite image asset — sent over Discord’s local named pipe. Nothing is uploaded to a Vite server.
Game Boost Reversible
Boost active Puck
  • High process prioritypriority
  • High-performance power planos
  • Background sampling pausedvite
  • TCP no-delay on Vite’s own socketsoptional

Four reversible changes for the game you are running: priority, the Windows High Performance plan, paused background work, and optional TCP no-delay that only affects Vite’s own short-lived HTTP sockets.

No magic FPS claims Boost reduces contention; it does not unlock frames or improve game-server routing. Every change is reverted when the game stops or you toggle it off.
